Privacy Policy

Last updated: 10 October 2026

"cn-video-maker" is a private tool used only by the owner of the YouTube channel 蟹哥来讲 (Xie Ge Lai Jiang) to publish the channel's own videos. It is not offered to the public and has no other users.

What the tool accesses

  • With the channel owner's permission (Google sign-in), it uses the YouTube API Services to upload the channel's own videos, set their titles, descriptions, thumbnails and playlists, and read basic statistics (views, likes, comments counts) for those videos.
  • It does not access any other person's data, and it does not read viewers' personal information.

How data is stored and shared

  • The sign-in token and video statistics are stored only on the channel owner's own computer.
  • No data is sold, shared with third parties, or used for advertising.
  • The owner can revoke the tool's access at any time at Google Account permissions; the stored token is then useless and can be deleted.

Google and YouTube terms

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
